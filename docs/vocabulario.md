# Vocabulário institucional

Toda tela, mensagem, e-mail e documento usa estes termos. A interface é sempre em português do Brasil.

| Use | Não use |
|---|---|
| voluntário | trabalhador (termo antigo), funcionário |
| frequentador | paciente, cliente |
| consulente | paciente |
| maca | leito |
| passe | tratamento |
| chamamento | recrutamento |
| dialogador | entrevistador |
| Diálogo Fraterno | triagem |
| assistido | beneficiário, carente |
| Acolhimento | recepção (como nome de função ou secretaria) |

## Estilo de texto
- Tom direto, fraterno e adulto.
- Sem travessões.
- Botões dizem exatamente o que fazem ("Salvar presença", "Confirmar alta").
- Mensagens de erro explicam o que aconteceu e o que fazer, sem pedir desculpas.
- Nome da casa: Lar de Seu Luiz (sigla LSL). Não usar "Centro Espiritualista".
